# دليل طنطا الأخضر

موقع عربي تفاعلي يساعد سكان طنطا يشاركوا في تشجير الشوارع ومتابعة الأشجار. بنطوّره للمشاركة في مسابقة «دليل طنطا الأخضر للتشجير المستدام للشوارع» بكلية الهندسة، جامعة طنطا. عبد الله مسؤول عن الرؤية التخطيطية ضمن فريق من تخطيط وتصميم عمراني، وهندسة الحاسب، وحاسبات ومعلومات. اختيار شارع التجربة وتأكيد المواعيد ومتطلبات التسليم لسه قيد الدراسة.

## خريطة المزايا

| المرحلة | اللي هنشتغل عليه |
| --- | --- |
| البداية | خريطة طنطا بنقطتين من `trees-demo.geojson`، وكل نقطة تفتح بطاقة باسمها ومعرّفها وحالتها التجريبية. |
| النسخة الأولى | ٦ نقاط تجريبية وموقع زراعة مؤقت يقدر المستخدم يغيّره أو يلغيه. الاختيار في الصفحة الحالية فقط ويختفي عند إعادة تحميلها. |
| الدليل العلمي | بطاقة لكل نوع فيها الاسم العربي والعلمي والصور والحجم عند النضج واحتياجات الشمس والتربة والري والظل وظروف الشوارع المناسبة. التقسيم حسب مناطق طنطا يتوقف على نتائج الدراسة. |
| ازرع شجرة | النسخة الأولى تجمع قياسات اختيارية لعرض الشارع والرصيف وعدد أدوار المبنيين وزاوية محور الشارع. الملخص يقدّر ارتفاع كل مبنى بـ٣ أمتار لكل دور ويبيّن البيانات الناقصة. بيانات النموذج مرتبطة بالموقع المؤقت داخل الصفحة. الترشيح العلمي وحساب الشمس والظل وإرسال الطلبات مراحل لاحقة. توفير الشتلات يتوقف على التنسيق مع الجهة المختصة. |
| ملف الشجرة | توثيق النوع والموقع وتاريخ الزراعة إذا كان معروفًا، وصور وملاحظات حالة ورعاية على فترات، مع خيار ذكر اسم المشارك. تميّز الخريطة بين الأشجار المرصودة أو المزروعة والمواقع المقترحة والبيانات التجريبية. |
| شارع التطبيق | مقارنة الوضع القائم والمقترح بالصور والمواقع وأسباب الاختيار، وقطاع يوضح علاقة الأشجار بالرصيف والمشاة والمباني. |
| توسعات لاحقة | تفاصيل الأحواض والرصف والري والرعاية، ودراسة دليل الأسطح ومعاينة شكل الشجرة أمام الواجهة. |

## تقدير الشمس في «ازرع شجرة»

الموقع يحسب ساعات الشمس المباشرة المحتملة في منتصف الرصيف تقريبًا في ٢١ يونيو و٢١ ديسمبر. يستخدم الإحداثيات وعرض الشارع والرصيف وارتفاع الواجهتين وزاوية محور الشارع. بيتحقق كل ٥ دقائق من حجب الواجهات للشمس، باستخدام [معادلات موقع الشمس من NOAA](https://gml.noaa.gov/grad/solcalc/solareqns.PDF). النطاق يغطي الاحتمالين لجهة الرصيف لأن النموذج لا يحدد الجهة. التقدير يفترض سماء صافية وواجهتين مستقيمتين ممتدتين. تفاصيل التربة والصرف والري والعوائق اختيارية.

نسبة ظل المشاة تحتاج أبعاد التاج ومسار المشاة وتوقيت الدراسة. ترشيح النوع يحتاج جدول أنواع موثّق لطنطا.

## تشغيل المعاينة محليًا

```sh
npm ci
npm run dev
```

افتح الرابط اللي يظهر في الطرفية. لفحص الأنواع وإنتاج نسخة جاهزة للاستضافة، شغّل `npm run build`.

## البيانات ومصدر الخريطة

- واجهة عربية من اليمين للشمال باستخدام React وTypeScript وVite وMapLibre GL JS.
- خدمة [OpenFreeMap](https://openfreemap.org/quick_start/) بتوفر نمط Liberty والبلاطات المتجهة بدون مفتاح في المعاينة. بيانات خريطة الأساس من [مساهمي OpenStreetMap](https://www.openstreetmap.org/copyright) وتستخدم مخطط OpenMapTiles. الإسناد ظاهر على الخريطة، وعرض البلاطات يتطلب اتصال بالإنترنت.
- ملف `trees-demo.geojson` فيه بيانات تجريبية. ترتيب الإحداثيات `[longitude, latitude]`. عند اختيار شارع التطبيق هنقارن تفاصيل خريطة الأساس بالواقع.
- أسماء الطرق بتفضّل الاسم العربي لو موجود في البيانات. سمك الطريق على الخريطة بيعتمد على فئته ومستوى التكبير. عرض الرصف والرصيف بالمتر يتوثّق من بيانات قياس منفصلة لشارع التطبيق.
